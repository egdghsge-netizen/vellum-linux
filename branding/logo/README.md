# Vellum Logo

The Vellum identity uses a layered, abstract symbol inspired by overlapping pages and leaves.

## Files
- `branding/logo/vellum-mark.svg` — transparent mark for app icons, branding, splash screens, and UI ornaments.
- `branding/logo/vellum-badge-dark.svg` — dark background variant for headers and splash-style presentations.

## Style
- Palette: `#101218`, `#191D27`, `#167BFF`, `#35D9EE`, `#66E8D1`, `#F5F7FA`
- Shape language: layered curved forms suggesting leaves/pages in motion
- No text is embedded in the main symbol, per the design brief

## Usage
Use the transparent SVG for interface elements and the dark badge for high-contrast presentations.
