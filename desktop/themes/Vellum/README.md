# Vellum desktop theme

This theme directory is the initial GTK theme scaffold. The GTK CSS defines palette tokens and a restrained dark surface; complete GTK/Cinnamon widget coverage remains in progress.

Color tokens: `#101218` deep black, `#191D27` graphite, `#167BFF` blue, `#35D9EE` cyan, `#66E8D1` aqua, `#F5F7FA` text, `#A6B0C0` secondary text.

Original Vellum artwork is in `branding/logo/`. This theme scaffold contains no third-party artwork.
