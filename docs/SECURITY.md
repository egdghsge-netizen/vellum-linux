# Security policy

- No telemetry or personal-data collection is included in this scaffold.
- Use official Mint repositories and trusted upstream application sources only. Do not add repositories without documenting ownership, signing, support, and removal procedures.
- Applications must not request or retain administrator passwords. Do not invoke `sudo` from GUI code.
- Keep Mint's security updates, firewall tooling, user permissions, and installer safeguards intact.
- Verify upstream ISO checksums/signatures and publish a SHA-256 for each Vellum ISO.
- Report security issues privately to the repository maintainer rather than publishing exploit details before a fix is available.

This is a project policy, not a claim that the current scaffold has undergone a security audit.
